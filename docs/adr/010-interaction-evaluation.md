# ADR-010: Keep interaction and detection experiments separate

Detection requires a confirmed TaskSpec shared across A/B/C/D. Interaction instead freezes initial missingness and a fixed answerable question contract for C/D. The existing source/freeze gates are reused with a distinct metric and condition list; the two execution commands reject mismatched protocols.

C uses real audit and revision subprocesses. The broker releases only requested answers, and a separate scorer reads the evaluator-only target and exhaustive risk labels. No model provider exists yet, so every D repetition remains blocked. Scripted answers are not scripted D, human participants or measured saved labor.

The first fixture intentionally includes normal, missing, unanswerable and budget-limited cases. Unresolved goals, excessive questions, false negatives and pending review work remain in the results. Missing scores disable aggregates; configuration drift suppresses all quality aggregates while retaining attempts and resource records. Policy is not optimized against these engineering results. M4/E remains deferred.
