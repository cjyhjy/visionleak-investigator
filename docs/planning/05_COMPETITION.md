## 2. 作品申报草稿

以下是拟议方案表述，必须在提交前对照实际完成状态。不得自动把“拟实现”改成“已实现”。

### 作品名称

VisionLeak Investigator——面向图像机器学习实验的证据驱动自适应审计智能体。

### 一句话简介

在不修改原始数据的前提下，理解实验目标、调用图像审计工具、补充必要证据，并给出可追溯、可复核的数据划分风险与修正建议。

### 目标用户与痛点

做图像分类实验的学生、研究人员及小型研发团队，往往需要自行协调去重工具、实体元数据、实验目标与人工复核。单纯图像相似结果无法独立判断是否违反当前实验的泛化目标。项目拟把这段分散流程组织为受约束的可验证任务。

此处是产品问题假设，尚不等于已完成用户访谈或市场验证。后续访谈按“真实使用记录”另列。

### 技术方案

复用固定版本 MoonBit VisionLeak Core 产生图像证据；新增 Python/openJiuwen 单 Agent 工作流，在工具白名单与总预算下选择检查、提出必要澄清、请求人工确认。程序负责证据校验、范围/成本核算与结论约束。借鉴 Harness²，以有界策略提案、试运行和独立评测研究审计策略改进，不允许 Agent 修改核心检测或验收标准。

### 拟验证的创新

- 将图像内容关系、来源/实体关系与实验目标分开建模，避免“相似即泄漏”的错误推断。
- 根据当前证据、缺失信息和预算组织后续检查，保留“无法判断/未覆盖”的真实边界。
- 通过独立评测选择领域化策略；比较固定规则与 Agent，报告全部优化成本与负结果。

以上是本项目设计贡献，不宣称这些通用概念全球首创，也不预设准确率/成本收益。

### 现有基础与新增内容

现有 Core 提供图像指纹、候选检索、证据与报告工具。新增 Investigator 负责目标与信息管理、Agent 决策、总预算、审计编排、结论验证和策略实验。每次申报应明确列出已有开源资产、版本及新增提交，避免把已有成果当本届全新研发。

### 验证方法

同工具池、同数据、可比预算，比较 Core 基础、全开、强规则、固定 Agent 和优化策略 Agent。新来源测试集与开发数据分离；真实模型实验和离线集成测试分开报告。

## 3. 三分钟演示脚本（拟议，不是现有视频）

| 区间 | 展示 | 不能伪装的部分 |
|---|---|---|
| 0:00—0:25 | 用户给数据与含糊目标，说明内容重复和实体重叠的区别 | 案例标“受控演示”，不冒充真实发现 |
| 0:25—0:55 | 真实 Core 基础扫描，显示证据和范围 | 不替换成硬编码动画 |

| 2:30—3:00 | 基线比较、未完成范围、下一步实验 | 无真实评测时展示“待验证”，不编造柱状图 |
