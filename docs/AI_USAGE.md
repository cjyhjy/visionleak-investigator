# AI 辅助、运行模式与来源声明

本项目由负责人授权 Codex 辅助阅读设计、编写实现和测试、整理文档、运行本地验收，并提交到独立公开 GitHub 仓库。自动生成的实现与文档不等于经过真人独立审查或用户研究；提交中的命令、日志、产物和测试是可核验的工程证据。

本文件区分两种不同活动：开发工具使用了 AI 辅助；**Investigator 的已保存应用实验没有调用任何模型服务**。项目 `model_calls=0` 指应用运行和评测，不表示开发助手本身没有使用语言模型。

| 运行来源 | 实际发生的事 | 不能据此宣称 |
|---|---|---|
| rules / A/B/C | 真实 Core、固定规则与确定性检查 | 真实模型自主决策 |
| SCRIPTED_TEST_ONLY | 本地测试回调输出动作，工具仍真实执行 | 模型实验、推理能力或 Agent 收益 |
| 脚本用户回答/复核 | 人工构造的输入 fixture | 真人参与、访谈结果、节省人工工时 |
| 历史证据修订 | 校验并复用已有图像证据，生成新解释 | 新执行了图像审计 |
| 控制故障 | 对新建合成运行注入失败、输入变化或报告缺失 | 真实业务事故的发生率 |

openJiuwen 仅在局部可选环境中用于无模型工作流及脚本控制器验收。没有当前项目已授权的 provider/model/endpoint/披露/预算契约，真实模式拒绝执行；不会因为其他环境中存在凭据而尝试调用。模型接入与 D 条件保持 blocked，E/M4 后置。

评测图片为程序生成或明确记录的受控变换。新平色、梯度难负例使用独立的合成来源记录定义标签；这些标签不证明自然照片的真实物理来源。旧 Core 数据只用于开发/回归，未作为新独立自然测试。没有下载外部自然图像、上传数据给应用模型或测得自然场景泛化收益。

Core 已有算法、SDK 和依赖不计为 Investigator 的新算法。许可与来源清单见根目录 `THIRD_PARTY_NOTICES.md` 和 `reports/licenses/`；负责人尚未为 Investigator 选择项目许可证。公开仓库授权不表示已发布软件包、接受赛事条款或正式提交材料。

可公开材料包括已授权的源码、设计、合成素材和工程证据。用户真实数据、新来源材料和模型提示记录不能因为这个仓库是公开的就自动加入提交。历史运行路径保留为证据，不是可直接跨机器使用的注册配置。
