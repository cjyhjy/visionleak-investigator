# VisionLeak Investigator 作品说明草稿

状态：依据当前实现更新的本地草稿，未报名或提交。真实单 Agent 部分、独立自然数据实验和负责人对赛事/许可的确认仍待完成。

VisionLeak Investigator 面向图像分类实验中的数据划分审计。它把固定版本的图像检测工具、实验目标、实体元数据、人工复核和总预算组织成可追溯流程，输出证据、范围缺口与只读修正建议。

已有 VisionLeak Core 负责字节/像素身份、感知与局部候选、匹配预算、报告身份和复验。Investigator 的新增工作是：宿主确认目标与字段语义、跨多次工具调用的总预算与证据约束、保留来源的解释修订、保守恢复、可读证据页、来源隔离与冻结评测。它没有重新发明 Core 的图像算法。

当前可演示的是确定性审计闭环、目标敏感的元数据风险解释、候选复核、低预算不完整结果和真实 Core 的 A/B/C 对照。单 Planner 宿主与 openJiuwen 工作流已完成无模型/脚本验收，但真实 provider 尚未接入，不能把这些演示称为真实模型 Agent 实验。

受控案例中，同一组声明实体在“新实体泛化”和“同实体新视角”下产生不同的风险解释；图像内容事实保持不变。平色、梯度负例会产生相似候选，系统仍保持候选级别，并在独立评分中保留误报，展示工具的真实局限。

演示脚本见 `docs/DEMO.md`，本地生成与核验命令见 README。脚本回答、人审 fixture、故障注入和历史证据复用均单独标注；目前没有真人研究、自然泄漏发现、准确率提升百分比或节省工时的结论，也没有录制冒充真实 Agent 的视频。

后续真实模型验收应完成主动澄清与补充取证/合理停止轨迹，再在相同工具、数据和预算下比较 C 与 D。若模型不优于规则，保留负结果并缩减其作用。策略优化 E 留待真实流程稳定之后。
